# 新电脑初始化指南

> 本文件供 opencode 读取。当检测到新电脑或环境未配好时，按本文件执行初始化。

## 什么时候执行

- 用户说「新电脑」「换电脑」「配置一下」「环境没配好」
- 或 opencode 发现依赖未装、定时任务没配

## 前置条件

1. 已安装 Node.js（v18+）
2. 已安装 Git
3. 已安装 opencode
4. 已 clone 项目仓库
5. 已配置 opencode 模型（`~/.config/opencode/opencode.jsonc` 里有对应 provider）

## 初始化步骤

### 1. 安装后端依赖

```bash
cd <项目目录>/server
npm install
```

### 2. 安装前端依赖（如有）

```bash
cd <项目目录>/src
npm install
```

### 3. 配置 .env 文件（如后端需要）

在后端目录创建 `.env` 文件（参考 `.env.example`），填入 API Key 等配置。

⚠️ `.env` 不进 git，每台电脑都要单独配。

### 3.5 安装 OCR 依赖（可选但推荐）

`scripts/ocr-image.py` 用 Windows 自带 OCR 引擎提取图片文字，在模型不支持识图时作为降级方案。需要 Python 3.10+。

**Windows：**
```powershell
pip install pillow winrt-Windows.Media.Ocr winrt-Windows.Graphics.Imaging winrt-Windows.Storage.Streams winrt-Windows.Foundation winrt-Windows.Foundation.Collections
```

**验证：**
```powershell
$env:PYTHONIOENCODING="utf-8"
python scripts/ocr-image.py "任意一张含文字的图片.jpg"
```

> macOS/Linux 暂不支持此脚本，用 tesseract 替代。
> 如提示"系统无 OCR 语言包"，去「设置 → 语言」添加中文语言包。

### 4. 配置定时任务（如需要）

项目 `scripts/` 目录下有脚本模板（sync.bat / sync.sh / auto-summary.js / plist），使用前搜索 `PROJECT_NAME` 替换成项目英文名。详细说明见 `scripts/README.md`。

#### Mac（launchd）

改完 plist 里的 WorkingDirectory 后：
```bash
cp scripts/com.PROJECT_NAME.*.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.PROJECT_NAME.auto-summary.plist
launchctl load ~/Library/LaunchAgents/com.PROJECT_NAME.sync.plist
launchctl list | grep PROJECT_NAME  # 验证
```

#### Windows（任务计划程序）

> 把 `PROJECT_NAME` 和 `PROJECT_PATH` 替换成项目英文名和项目绝对路径。

```cmd
schtasks /create /tn "PROJECT_NAME_Sync" /tr "PROJECT_PATH\scripts\sync.bat" /sc daily /st 18:50 /f
schtasks /create /tn "PROJECT_NAME_AutoSummary" /tr "PROJECT_PATH\scripts\auto-summary.bat" /sc daily /st 18:40 /f
schtasks /query /tn PROJECT_NAME_Sync  # 验证
```

### 5. 配置 skills 软链（如项目用了 opencode skills）

如果项目依赖工作台的 skills（通过软链指向工作台的 `.skills-mirror/skills/`），确保软链已配好：

**Mac：**
```bash
ln -s <工作台路径>/.skills-mirror/skills ~/.config/opencode/skills
```

**Windows（管理员PowerShell）：**
```powershell
cmd /c mklink /D "%USERPROFILE%\.config\opencode\skills" "<工作台路径>\.skills-mirror\skills"
```

### 6. 验证

```bash
# 验证 git
cd <项目目录>
git status

# 验证后端
cd server && node index.js

# 验证定时任务（如配了）
# Mac:
launchctl list | grep <项目名>
# Windows:
schtasks /query /tn <任务名>
```

## 跨电脑同步机制

```
任意电脑改文件
  → 定时任务自动 commit + push
  或手动 commit + push

另一台电脑
  → 开工前 git pull
  → 拿到最新代码
```

**关键：每天开工前先 `git pull`，结束工作时确保已 push。**

## 注意事项

- `.env` 文件每台电脑单独配，不进 git
- Windows 创建软链需要管理员权限
- 软链配好后只需配一次，以后 `git pull` 就能自动拿到最新代码
