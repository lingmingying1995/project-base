# 产出

> AI 和系统自动生成的文件。不需要手动编辑。
> AI 开工时读这里的内容建立上下文。

## 目录结构

| 子目录 | 谁产出 | 给谁看 | 内容 |
|--------|--------|--------|------|
| `每日总结/` | AI 分析对话生成 | AI 读它建上下文 | 有认知增量的内容（做了什么+踩的坑+沉淀的经验） |
| `决策记录/` | AI 主动记录决策 | 你回看决策脉络 | 决策背景+方案对比+最终决策+可复用标准 |
| `任务日志/` | 定时任务脚本自动记录 | 你查任务有没有跑成功 | 执行时间+结果+失败原因 |
| `测试报告/` | 全量测试脚本生成 | AI + 你查问题 | 引用一致性、接口、页面完整性检查结果 |

## 规则

- 不手动编辑这里的文件
- 每日总结：AI 在对话中实时记录 + 定时归档脚本补充
- 任务日志：脚本每次执行追加一行，不覆盖
- 测试报告：每周一份，旧的保留
- 详见 `规则/自动化任务规则.md` 和 `规则/文件组织规则.md` 的对话记录规则
